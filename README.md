# LOGITEX · Ecosistema de Sistemas 360

App HTML autocontenida (un solo `index.html`) con la vista 360 de las herramientas de LOGITEX, el Maestro de Datos editable, fichas por sistema, asistente LOGI e idioma ES / EN / PT.

- Versión actual: **v13**
- Publicada en Vercel desde la rama `main` (cada push publica una versión nueva).
- Los cambios del Maestro de Datos se guardan en el navegador de cada usuario (localStorage). Para pasar datos entre equipos o dominios use Exportar / Importar Excel.
